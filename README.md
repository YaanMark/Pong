# 🏓 Pong

A simple **Pong** game clone built in **Java**, developed as an IntelliJ IDEA project.

This project recreates the classic 1972 Atari arcade game, allowing two players to compete against each other using paddles to hit a ball back and forth on the screen.

---

## 📋 Features

✅ Paddle movement and collision detection

✅ Ball physics and bouncing mechanics

✅ Score tracking

✅ Simple and responsive game window

✅ Object-oriented game architecture

---

## 🛠️ Technologies Used

### Language


- Java

### Graphics


- Java Swing / AWT

## ⚙️ Installation


### 1. Clone the repository

```
git clone https://github.com/YaanMark/Pong.git
```

### 2. Open the project


Open the project folder in **IntelliJ IDEA** (or any Java-compatible IDE).

### 3. Build the project


Make sure a **JDK (Java Development Kit)** is configured in your IDE, then build the project.

---

## 🚀 Running the Application


### Run from the IDE


Open the main class located in the `src` folder and run it directly from IntelliJ IDEA.

### Run from the terminal


```
javac -d out src/*.java
java -cp out Main
```

> ⚠️ Adjust the class name above according to the actual main class inside the `src` folder.

## 💻 Gameplay


The game provides a simple and intuitive Pong experience where players can:

- Move their paddles to the left and right
- Hit the ball back to the opponent
- Score points when the opponent misses the ball
